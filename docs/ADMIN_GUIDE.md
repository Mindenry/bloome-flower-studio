# Admin guide — คู่มือการใช้งานหลังบ้าน

เข้าสู่ระบบที่ `/{locale}/admin` ด้วยบัญชีพนักงาน (ไม่ใช่บัญชีลูกค้า) เมนูจะแสดงตามสิทธิ์ของบทบาทที่ได้รับ

## บทบาทและสิทธิ์ (Roles)

| Role | เหมาะกับ | สิทธิ์หลัก |
| --- | --- | --- |
| Super Admin | เจ้าของร้าน | ทุกอย่าง รวมถึงพนักงานและตั้งค่า |
| Admin | ผู้จัดการร้าน | งานประจำวันทั้งหมด ยกเว้นจัดการพนักงาน/ตั้งค่าระบบ |
| Product Manager | ทีมสินค้า | สินค้า หมวดหมู่ สต็อก (ดู) เนื้อหา รายงาน |
| Order Manager | ทีมปฏิบัติการ | คำสั่งซื้อ การชำระเงิน ลูกค้า (ดู) รายงาน |
| Inventory Manager | ทีมคลัง | สต็อก ล็อตสินค้า ความสด รายงาน |
| Customer Support | ทีมบริการ | คำสั่งซื้อ (ดู) ลูกค้า รีวิว |
| Content Manager | ทีมคอนเทนต์ | หน้าเว็บ บทความ แบนเนอร์ การแจ้งเตือน |

สิทธิ์ถูกตรวจที่เซิร์ฟเวอร์ทุกครั้ง (ไม่ใช่แค่ซ่อนเมนู) ปรับได้ที่ **บทบาทและสิทธิ์**

## Dashboard

- เลือกช่วงเวลา: วันนี้ / เมื่อวาน / 7 วัน / 30 วัน / เดือนนี้ / เดือนที่แล้ว
- ตัวเลขทั้งหมดมาจากฐานข้อมูลจริง: ยอดขาย (เฉพาะที่ชำระสำเร็จ), รายได้สุทธิหลังคืนเงิน, จำนวนคำสั่งซื้อแยกสถานะ, ยอดเฉลี่ย, ลูกค้าใหม่/กลับมาซื้อ, สินค้าใกล้หมด, สินค้าขายดี, แนวโน้มรายได้, ยอดขายตามหมวดหมู่ และสัดส่วนช่องทางชำระเงิน

## สินค้า (Products)

1. **เพิ่มสินค้า** → กรอกแท็บ ข้อมูลทั่วไป (ชื่อ TH/EN, SKU, slug, หมวดหมู่, คำอธิบาย, ข้อมูลดอกไม้)
2. **รูปภาพ** → ลากไฟล์หรือคลิกอัปโหลด (JPG/PNG/WebP ≤ 8MB) ลำดับแรกคือภาพหลัก ใส่ Alt text ทั้งสองภาษา
3. **ราคา** → ราคาปกติ/ราคาโปรโมชัน/ราคาทุน (แสดงเฉพาะผู้มีสิทธิ์ตั้งค่า) หน่วยบาท
4. **สต็อก** → จำนวนและจุดแจ้งเตือนสินค้าใกล้หมด
5. **โอกาสที่เหมาะ** → ติ๊กได้หลายโอกาส สินค้าจะแสดงทั้งในหมวดหมู่และหน้าของแต่ละโอกาส
6. **ตัวเลือก (Variants)** → หลังบันทึกแล้ว เพิ่มขนาด/รูปแบบพร้อมราคาเพิ่มและสต็อกแยก (หน่วยบาท)
7. **การเผยแพร่** → ฉบับร่าง / เผยแพร่ / ตั้งเวลา / เก็บถาวร พร้อมป้ายสินค้าใหม่และสินค้าแนะนำ
8. ปุ่มในหน้ารายการ: เผยแพร่/ยกเลิก, ทำสำเนา, เก็บถาวร, กู้คืน, ลบ (ระบบจะเก็บถาวรแทนการลบหากสินค้าเคยถูกสั่งซื้อ)

> ราคาที่กรอกเป็น **บาท** ระบบแปลงเป็นสตางค์และคำนวณใหม่ทั้งหมดฝั่งเซิร์ฟเวอร์

## คลังสินค้า (Inventory)

- ปรับสต็อก: รับเข้า / ตัดออก / ปรับปรุง / ของเสีย พร้อมหมายเหตุ
- บันทึกล็อต (Batch) และวันหมดอายุเพื่อติดตามความสดของดอกไม้
- ประวัติการเคลื่อนไหวทั้งหมดบันทึกอัตโนมัติ (รวมการขาย การยกเลิก และการคืนสต็อกเมื่อหมดเวลาชำระ)

## คำสั่งซื้อ (Orders)

1. ค้นหาด้วยเลขคำสั่งซื้อ/อีเมล/ชื่อ หรือกรองตามสถานะ
2. เปิดคำสั่งซื้อ → ดูรายการ สแนปช็อตราคา ที่อยู่ผู้รับ การ์ดข้อความ และไทม์ไลน์
3. **ยืนยันการชำระเงิน** (โอนเงิน) เมื่อตรวจสอบสลิปแล้ว → สถานะเป็นชำระเงิน
4. อัปเดตสถานะตามลำดับ: ยืนยัน → เตรียมสินค้า → จัดดอกไม้ → ตรวจคุณภาพ → พร้อมส่ง → กำลังส่ง → ส่งสำเร็จ (ระบบบล็อกการข้ามขั้น)
5. เพิ่มเลขพัสดุ/ขนส่ง, บันทึกภายใน (ลูกค้าไม่เห็น), ข้อความถึงลูกค้า
6. คืนเงิน: เต็ม/บางส่วน พร้อมเหตุผล (รองรับทั้งผ่านผู้ให้บริการและบันทึกด้วยตนเอง)
7. พิมพ์เอกสาร: ใบเสร็จ, ใบจัดสินค้า, ใบส่งของ, รายการตรวจสอบการจัดดอกไม้

## ลูกค้า (Customers)

- ค้นหา ดูประวัติคำสั่งซื้อ ยอดใช้จ่าย ที่อยู่ และสถานะการยินยอมรับข่าวสาร
- ส่งออก CSV ได้ (บันทึกใน Activity log)

## โค้ดส่วนลด (Coupons)

- ประเภท: จำนวนเงินคงที่ (สตางค์), เปอร์เซ็นต์ (basis points: 1000 = 10%), ส่งฟรี
- เงื่อนไข: ยอดขั้นต่ำ, ส่วนลดสูงสุด, จำนวนสิทธิ์รวม, ต่อลูกค้า, ช่วงวันที่, เฉพาะสินค้า/หมวดหมู่
- ระบบตรวจทุกเงื่อนไขฝั่งเซิร์ฟเวอร์และกันการใช้เกินสิทธิ์

## รีวิว (Reviews)

- รีวิวจากผู้ซื้อที่ได้รับสินค้าแล้วเท่านั้น (1 รีวิวต่อรายการสินค้า)
- อนุมัติ/ปฏิเสธ และตอบกลับลูกค้าได้ รีวิวที่อนุมัติจะแสดงบนหน้าเว็บ

## เนื้อหาเว็บไซต์ (Content)

- แบนเนอร์: hero, ประกาศ, คอลเลกชันพิเศษ, โซเชียล (กำหนดช่วงเวลาเปิด/ปิดได้)
- หน้าเว็บ: about, contact, นโยบายต่าง ๆ (แก้ข้อความ TH/EN และ SEO)
- คำถามที่พบบ่อย และแกลเลอรี Instagram

## บทความ (Journal)

สร้าง/แก้ไขบทความสองภาษา กำหนดหมวด ภาพปก และเผยแพร่ ระบบสร้าง metadata และ JSON-LD ให้อัตโนมัติ

## การแจ้งเตือน (Notifications)

- กล่องแจ้งเตือนภายในสำหรับทีม
- ส่งข้อความถึงลูกค้า: เฉพาะผู้ที่ยินยอมรับข่าวสาร (PDPA) หรือลูกค้าทั้งหมดสำหรับประกาศที่เกี่ยวข้องกับการให้บริการ

## รายงาน (Reports)

ยอดขายรายวัน รายละเอียดคำสั่งซื้อ ยอดตามหมวดหมู่ และส่งออก CSV ตามช่วงวันที่

## พนักงานและสิทธิ์ (Staff & Roles)

- เพิ่มพนักงานด้วยอีเมล/รหัสผ่านชั่วคราว และกำหนดบทบาท
- ระงับการใช้งานได้ทันที (révoque ทุก session)
- สร้างบทบาทใหม่และเลือกสิทธิ์รายการ (view/create/update/delete/approve/export/settings)

## ตั้งค่าร้าน (Settings)

ข้อมูลร้าน ติดต่อ โลโก้/favicon, ภาษี (VAT 7% รวมในราคา), ค่าจัดส่ง/ยอดส่งฟรี, เวลาตัดรับออเดอร์, ช่วงเวลาจัดส่ง, วันหยุดร้าน, ช่องทางชำระเงิน, SEO และสถานะการเชื่อมต่อ (READY / CONFIGURE)

ความลับ (Channel secret, API keys) ตั้งค่าใน `.env` เท่านั้น ไม่แสดงบนหน้าจอ

## รูปภาพสินค้า

ค่าเริ่มต้นของระบบตัวอย่างใช้ภาพถ่ายดอกไม้จริงจาก Pexels (ลิขสิทธิ์ใช้งานเชิงพาณิชย์ฟรี) โดยระบุเครดิตที่หน้า `/th/photo-credits` เมื่อมีภาพถ่ายสตูดิโอของร้านเอง ให้อัปโหลดแทนที่ผ่าน **สินค้า → รูปภาพ** หรือคลังสื่อ ระบบจะบีบอัดเป็น WebP และลบข้อมูล EXIF ให้อัตโนมัติ
